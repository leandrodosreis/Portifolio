## 📌 Sobre o projeto
Este projeto é uma landing page de portfólio pessoal desenvolvida para apresentar minhas habilidades, projetos e informações profissionais de forma clara e responsiva.

O objetivo é criar uma interface moderna que funcione como vitrine do meu desenvolvimento como programador.

Confira aqui: https://leandrodosreis.github.io/Portifolio/

## 🚀 Tecnologias utilizadas
- HTML5  
- CSS3  
- JavaScript

## ⚙️ Funcionalidades
- 📱 Layout responsivo (mobile e desktop)
- 📂 Seção de projetos
- 👨‍💻 Apresentação profissional
- 📞 Formulário de contato funcional
- 🎨 Interface moderna e organizada
